## Learned Workspace Facts
- This repository is a monorepo: use the checkout root (e.g. this machine: `C:\Users\adgv\Documents\Projects\idsculpt2026`). An older path `…/idsculpt` on Linux is a different checkout.
- Conversation transcripts for memory mining on this project live under `C:\Users\adgv\.cursor\projects\c-Users-adgv-Documents-Projects-idsculpt2026\agent-transcripts` (per-workspace path; not the generic `…/idsculpt/agent-transcripts` from another environment).
- The web app does not use `next-themes` or a `ThemeProvider`; it does not toggle a `dark` class on `<html>` for global theme switching (shared UI such as toasts uses a fixed light theme where needed).
- Header: section-driven contrast via `use-header-text-from-sections` — `main` sections use both `id` and `data-header-text` (`light` = white header text, `dark` = black). Logo (i/s), desktop nav, and "Email us" share `headerPillSurfaceClassnames` (rounded glassy pill with backdrop blur; `light` sections → `bg-black/40`, `dark` → `bg-white/50`). The active route shows a small square (`bg-current`) left of the label. The header CTA is a direct `mailto:` ("Email us" + square), not a contact dropdown; there is no phone CTA in the header. Contact bands on homepage, gallery, and about use shared `ContactSectionPills` — uppercase "Email Us" + "Call Us" (`tel:+393737742584`).
- Nav link click "neon" effect uses the CSS class `header-nav-neon-blink` in `apps/web/src/index.css` and respects `prefers-reduced-motion`. While the animation runs, the link's reduced opacity (inactive items) is lifted so the flicker is visible; Framer's `navClassnames` `transition` is disabled during the flash to avoid smearing the effect.
- Global film-grain layer: `FilmGrainOverlay` (`film-grain-overlay.tsx`) — inline SVG `feTurbulence` noise (replaces legacy 7.5MB `bg-noize.png`), applied in `site-preloader.tsx` (not inside a `framer-motion` `motion` child). It is `absolute` on the preloader's outer `relative` shell so it tiles and scrolls with the page; shown only after the site preloader dismisses. Z-order stays below the fixed header (`z-30` vs header `z-40`); `pointer-events: none` and `mix-blend-overlay` for blending.
- Homepage hero: background is `HeroShaderBackground` via client wrapper `hero-shader-background-lazy.tsx` (`dynamic` + `ssr: false`); WebGPU (`@basementstudio/shader-lab`) on desktop fine pointer only — CSS gradient fallback on touch/coarse pointer. Shader stays mounted after first load (pause off-screen with `visibility` + `animate: false`; unmounting re-inits WebGPU and janks scroll-back). Cursor follow on the hero band; Discover hover drives a separate shader accent. Only the `Identity/Sculpt` span gets a top-to-bottom blur (duplicate text layer with `blur-2xl` and `mask-image: linear-gradient(to bottom, white, transparent ~70%)` — use `white` at the top of the mask, not `black`, or the overlay stays invisible). A "Discover" pill (square + label, like header Email us) sits under the headline and links to `#work`; headline and CTA use `relative z-10` above the shader.
- Homepage work grid (`id="work"`): each card is an `aspect-square` `rounded-2xl` image container (no overlay caption on the image); title and type sit below centered with a small black square marker (gallery-style). Cards hover-scale and link to `/gallery`. Assets use `Frame 1221.png` (Tenryuu) / `Frame 121.png` (Chili Riders).
- Footer glow: `FooterDiaGradient` — fixed `90dvh` band at the viewport bottom; default `DiaGradient` rainbow bars (not Peaked); scroll-linked `scaleY` reveal via `scrollBasis="anchor"` + `scrollAnchor="#site-footer"` on contact/footer sections; scroll progress measured on a static wrapper (not the scaled layer). Lenis in `providers.tsx` is desktop-only (disabled on touch/coarse pointer / `prefers-reduced-motion`); native scroll bridges `app-scroll` when Lenis is off so scroll-linked UI still updates.
- Gallery: `gallery-view-toggle.tsx` filters All work vs Case studies (`isCaseStudy` on projects; Case studies tab disabled until any exist — currently none). Cards are `aspect-square` with title/type inside the container; `next/image` uses `unoptimized` only in development — production serves AVIF/WebP via `next.config.ts`; preview containers have no layout inset/padding (margins baked into PNGs); multi-image cards paginate with shared-axis slide transitions (directional enter/exit, respects `prefers-reduced-motion`).
- About page: `WordStickersPlayground` peel stickers via vendored [sticker-forge](https://github.com/CatsJuice/sticker-forge) at `public/embed/sticker-forge.es.js` (lazy-loaded from `sticker-forge-loader.ts`). Team carousel (`about-team-carousel.tsx`): cards are `420×680px`; per-member WebGPU shaders on cards (member palette colors; pause when `#about-team` off-screen; only centered card animates — side cards static; shaders stay mounted). Portraits `object-cover object-bottom`; active (center) card has no image blend — side cards keep per-member Figma blend modes; desktop card click selects center.
- `framer-motion` imports are from the package `framer-motion` (this project does not use `motion/react`).
